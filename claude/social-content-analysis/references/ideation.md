# Ideation And Repurposing

Use this reference when the user wants ideas after analyzing social content.

## Turn Analysis Into Ideas

For each source item, extract:

- core insight
- reusable hook
- audience tension
- proof mechanism
- format pattern
- possible adaptation
- risk if copied too closely

## Idea Types

- Post angles.
- Thread outlines.
- Short-form video scripts.
- Carousel structures.
- Newsletter/email angles.
- Landing page sections.
- Product feature ideas.
- Community prompts.
- Ads.
- FAQ/support content.
- Blog outlines.

## Hook Transformations

Transform hooks by changing:

- audience
- problem
- promise
- proof
- contrarian angle
- timeline
- cost of inaction
- before/after state
- misconception
- checklist
- teardown
- comparison

## Repurposing Workflow

1. Keep the insight.
2. Change the surface expression.
3. Adapt to platform constraints.
4. Match the user's voice and product stage.
5. Add original examples or domain-specific proof.
6. Create 3-10 variants when exploration is useful.

## Content Strategy Output

When asked for broader strategy, produce:

- content pillars
- recurring series ideas
- example hooks
- formats to test
- evidence needed
- cadence suggestion if requested
- measurement plan

## Idea Quality Bar

Good ideas are:

- specific to the user's audience
- clearly different from the source
- easy to test
- tied to a business or creative goal
- realistic for the user's production capacity
