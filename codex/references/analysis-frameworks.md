# Analysis Frameworks

Use these frameworks depending on the user's goal.

## Quick Post Analysis

- Core message: what is the post actually saying?
- Hook: what makes someone stop?
- Promise: what benefit, curiosity, conflict, or identity signal appears?
- Proof: what evidence, example, metric, story, or authority supports it?
- Format: text, carousel, short video, long video, meme, screenshot, reply, thread.
- CTA: what action does it ask for?
- Friction: what is confusing, generic, excessive, or missing?

## Audience Analysis

- Intended audience.
- Pain point or desire.
- Level of awareness: unaware, problem-aware, solution-aware, product-aware.
- Insider language or community references.
- Emotional trigger: aspiration, fear, status, relief, curiosity, belonging, anger, humor.
- Trust signals.
- Objections likely present in comments.

## Comment Analysis

Group comments into themes:

- agreement
- disagreement
- questions
- objections
- jokes/memes
- requests
- testimonials
- confusion
- criticism
- product/support issues

Avoid claiming a theme is dominant unless there is enough sample size or visible ranking.

## Account/Profile Analysis

Look for:

- positioning
- repeated topics
- content pillars
- posting formats
- hook style
- visual identity
- offers/products
- audience interaction
- authority signals
- gaps and opportunities

## Competitor/Reference Analysis

Compare:

- content pillars
- hooks
- offers
- proof style
- comment sentiment
- posting cadence if visible
- format mix
- audience sophistication
- differentiation opportunities

Do not copy. Extract reusable principles.

## Trend Analysis

For trends:

- verify recency if possible
- identify the underlying mechanic
- separate trend format from trend topic
- note platform-specific context
- propose adaptations that fit the user's brand/product
