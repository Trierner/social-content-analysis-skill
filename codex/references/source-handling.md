# Source Handling

Use this reference when deciding how to inspect and describe social media material.

## Accepted Source Types

- Public links.
- Screenshots.
- Pasted post text.
- Pasted comments.
- Video/audio transcripts.
- Social exports or CSVs provided by the user.
- Analytics screenshots or exported metrics.
- Current browser page when the user has opened one.
- User-owned private content provided directly in chat or files.

## Access Rules

- Use public pages normally when available.
- If the content is behind login, paywall, private account, disappearing story, or app-only view, ask the user to provide screenshots, text, transcript, or export.
- Do not bypass login, rate limits, platform protections, or private account restrictions.
- Do not scrape at scale unless the user explicitly owns the data and the method is allowed.

## Evidence Labels

Use clear labels:

- Observed: directly visible in provided content.
- Inferred: reasonable interpretation from visible evidence.
- Unknown: not visible or not provided.
- Needs verification: likely to change or requires current/live confirmation.

## Metadata To Preserve

Capture when visible:

- platform
- account/creator/brand
- date/time
- format: post, thread, reel, short, story, live, carousel, comment, profile
- visible metrics: likes, comments, shares, saves, views
- caption/text
- visual elements
- call to action
- comment themes
- linked product/site/community

## Citation Rules

- Cite public URLs when using web content.
- For screenshots or user-provided private content, say "user-provided screenshot/content" instead of inventing a URL.
- Do not quote long copyrighted passages. Summarize and use short excerpts only when needed.
